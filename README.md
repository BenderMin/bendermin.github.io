# 🕯️ Ritual — Інструкція з розгортання

## Файли проекту
- `index.html` — головний додаток
- `manifest.json` — PWA маніфест
- `sw.js` — сервіс-воркер (офлайн + пуші)

> **Іконки:** Потрібно додати `icon-192.png` і `icon-512.png` (ваш логотип/іконка).
> Можна згенерувати безкоштовно на https://realfavicongenerator.net

---

## 🚀 Варіант 1: Vercel (рекомендовано, 5 хвилин)

1. Зареєструйтесь на https://vercel.com (безкоштовно)
2. Встановіть Vercel CLI: `npm i -g vercel`
3. Перейдіть у папку з файлами: `cd habit-tracker`
4. Запустіть: `vercel`
5. Слідуйте інструкціям — отримаєте посилання типу `ritual.vercel.app`

---

## 🚀 Варіант 2: GitHub Pages (безкоштовно назавжди)

1. Створіть репозиторій на https://github.com
2. Завантажте файли (index.html, manifest.json, sw.js, іконки)
3. Settings → Pages → Source: main branch → /root
4. Ваш сайт: `ваш-нік.github.io/назва-репо`

---

## 📱 Встановлення на телефон

### iOS (Safari)
1. Відкрийте сайт у Safari
2. Кнопка "Поділитись" (квадрат зі стрілкою)
3. "На екран Дому"
4. Готово — іконка з'явиться як справжній додаток

### Android (Chrome)
1. Відкрийте сайт у Chrome
2. З'явиться банер "Встановити Ritual" — натисніть
3. Або: меню (три крапки) → "Встановити додаток"

---

## 🔔 Пуш-повідомлення

У вкладці "Сповіщення" в додатку:
1. Натисніть "Дозволити сповіщення"
2. Увімкніть ранковий / вечірній нагадувач
3. Встановіть зручний час
4. Перевірте кнопкою "Тест сповіщення"

**Важливо:** Сповіщення працюють поки вкладка браузера відкрита.
Для фонових пушів потрібен сервер (Firebase FCM — безкоштовний tier).

---

## 💡 Поради

- Дані зберігаються в localStorage — тільки на вашому пристрої
- Для синхронізації між пристроями — додайте Supabase (безкоштовно до 500MB)
- Додаток працює офлайн після першого відвідування
